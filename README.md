# Welcome to pseudos!

## What is pseudos?
pseudos is a pseudo-OS made in Python.
It includes a virtual disk where you can store and put things into.

## What do I need to run it?
If you want to know what you need to pre-install, check `pseudos_need.txt`.

## What to do if I find a bug?
You have 2 options:
1. Report it to the official pseudos GitHub repository.
2. Repair it yourself in the code.

You can change the pseudos kernel code as you like!
Dont have a function that you want to use? Add it to `boxshell`!
